# Run All Fix-Mode Commands

Run the discovery script that finds all `avm-*.md` commands supporting fix mode and executes each one sequentially on the given PIL file.

```
~/.claude/commands/avm-run-all-fix.sh $ARGUMENTS
```

Run the command above using Bash. Do not modify the script or add extra arguments. Report the summary output when done.
